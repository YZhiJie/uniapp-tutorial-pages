12. 已知限制（BLOCKED 原因） ​

  1. 小程序真机演示：本机仅有微信开发者工具（已登录），构建产物 appid 为占位 wx0000000000000000；无支付宝 / 抖音 / 百度 IDE，无真机、商户号与上传私钥，因此「微信/支付宝/抖音三端全真演示、QQ/百度模拟器核心链路」无法执行。
  2. H5 提交订单/支付：浏览器自动化对固定底栏按钮判定为视口外，未能完成点击验证，需人工或真机补测。
  3. 真实后端与上传：未配置 VITE_API_BASE_URL，且无上传域名/鉴权密钥，上传走 Mock 并返回 mock:// 地址；ci:upload:* 按设计跳过（exit 0），不产生假成功。
  4. 埋点：客户端已实现事件缓冲、批量上报、会话内曝光去重与离线持久化补发（utils/track.ts + composables/useExposure.ts），但默认上报到 Mock POST /track/events，未接真实采集服务与归因字段。
  5. 配置时效：前台 10s 轮询，后台与冷启动依赖启动拉取；匿名身份桶号随匿名 ID 变化，属预期行为。
  6. 客服能力：SupportProvider 已实现，原生客服需 VITE_SUPPORT_CORP_ID + VITE_SUPPORT_SERVICE_URL 齐全；当前未配置，故各端均走手机号/邮箱降级（H5 已实测弹层与复制）。
