高阶组件说明（props / emit / slot / 使用示例） ​

与 src/components/business、src/components/common 实现同步。所有组件均为 <script setup> + TypeScript，样式基于 styles/tokens.scss 设计变量。

可运行示例：启动 H5 后打开 http://localhost:5173/pages-sub/dev/components/index（或「我的 → 工程演练 → 组件演示」），页面同时渲染 Skeleton / EmptyState / LoadMore / CountDown / GoodsCard / WaterfallFlow / FormSchema / PopupManager 八个区块，可直接对照下方 props 与用法。

页面级组件（NavBar / SkuPopup / LiveProductBar / SeckillBar / NetworkBanner）依赖具体页面数据与全局状态，见各自「生产使用」位置。

2. VirtualList 虚拟滚动列表 ​

文件：src/components/business/VirtualList.vue

props类型默认说明
listRecord<string, unknown>[]必填数据源
itemHeightnumber0定高模式行高（px）
dynamicbooleanfalse动态高模式，测量真实渲染高度
heightstring | number'100%'滚动容器高度，数字按 px
buffernumber3可视区外额外渲染条数
itemKeystring'id'唯一键字段
estimatedItemHeightnumber80动态高模式未测量前的估算高度
  • emit：scroll({ scrollTop })、loadMore()、itemClick({ item, index })
  • slot：default，作用域参数 { item, index }
  • expose：scrollTo(offset)、scrollToIndex(index, offset?)
vue
<VirtualList
  ref="listRef"
  :list="rows"
  :item-height="96"
  height="66vh"
  @scroll="onScroll"
  @load-more="loadMore"
>
  <template #default="{ item, index }">
    <view>{{ index + 1 }} - {{ item.title }}</view>
  </template>
</VirtualList>

1000 条压测入口：我的 → 工程演练 → 性能验收 · 长列表，页面 src/pages-sub/dev/long-list/index.vue。

生产使用：订单列表 src/pages-sub/order/list/index.vue（dynamic 动态高 + @load-more 触底分页）；收藏列表 src/pages-sub/user/favorites/index.vue（两列数据按「一行两件」分块后虚拟化）。

13. FormSchema 配置化表单 ​

文件：src/components/common/FormSchema.vue（类型与纯校验在 src/utils/form-schema.ts）

props类型默认说明
modelValueFormModel必填表单模型，字段 key → 值
fieldsFormField[]必填字段配置：type / placeholder / maxlength / group / options / validator / visible
labelWidthnumber140左侧标签宽度（rpx）
  • emit：update:modelValue(model)
  • expose：validate()（校验可见字段，失败弹首个错误）、reset()
  • 字段类型：text / number / textarea / region（省市区 picker）/ tags（单选标签）/ switch
vue
<FormSchema
  ref="formRef"
  :model-value="form"
  :fields="fields"
  @update:model-value="onFormUpdate"
/>
ts
const fields: FormField[] = [
  { key: 'mobile', label: '手机号', type: 'number', maxlength: 11,
    validator: (value) => (isMobile(String(value ?? '')) ? '' : '请输入正确的 11 位手机号') },
  { key: 'custom', label: '自定义标签', type: 'text',
    visible: (model) => model.tag === 'OTHER',
    validator: (value) => (String(value ?? '').trim() ? '' : '请填写自定义标签') },
]
