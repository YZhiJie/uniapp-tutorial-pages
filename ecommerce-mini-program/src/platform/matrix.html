5. 能力探测约定 ​

ts
// ✅ 业务/Provider 内部推荐写法
const canUseLivePlayer = typeof uni.createLivePlayerContext === 'function'

// ✅ 平台适配层内部允许
// #ifdef MP-WEIXIN
...
// #endif

// ❌ 禁止出现在 pages / components/business / stores / api
// #ifdef MP-WEIXIN
  • 判定顺序：API 存在性 → uni.canIUse → 平台兜底实现，三者都不可用时返回明确的 unsupported 状态，由 UI 展示降级态。
  • 禁止在业务层通过 uni.getSystemInfoSync().platform 分支做能力判断。
  • 新增能力必须同步更新本矩阵，并在 platform/ 增加对应实现与降级路径。

6. CI 校验 ​

阶段五加入以下检查：

  • grep -r "#ifdef" src/pages src/components/business src/stores src/api 必须为空。
  • grep -r "getSystemInfoSync().platform" src 只允许出现在 platform/。
  • 六端 uni build 零报错；vue-tsc --noEmit 零错误。
