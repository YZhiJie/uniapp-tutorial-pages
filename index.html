教程地图 ​

整套教程围绕「先原理、再基建、后业务」的主线展开，建议按顺序学习，也可按兴趣跳读：

① 认识 uni-app

定位与生态、双线程原理、四端产物对比

② 开发环境搭建

HBuilderX 与 CLI + Vite + TS、pnpm 工程化

③ 内置与自定义组件

内置组件体系、组件通信、跨端 UI 封装

④ API 调用与封装

uni.request、拦截器、重试、类型安全

⑤ 路由与页面跳转

pages.json、页面栈、路由守卫与鉴权

⑥ 状态管理

Pinia 组合式 Store、持久化、Vuex 迁移

⑦ 跨平台适配

四端差异矩阵、条件编译、权限封装

⑧ 性能优化

启动与渲染度量、分包、长列表、包体积

⑨ 电商应用实战

商品/购物车/订单/支付链路与状态机

⑩ 社交应用实战

登录、Feed 流、聊天、WebSocket 实时通信

⑪ 工具类应用实战

扫码/定位/文件/分享与跨端工具箱

每个模块的固定结构 ​

  1. 基础入门 —— 这是什么、为什么需要、最小可运行示例
  2. 进阶应用 —— 工程化封装、类型设计、边界条件与最佳实践
  3. 实战案例 —— 真实业务链路、练习题与可迁移的代码骨架
