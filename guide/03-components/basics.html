3.1 基础入门：内置组件体系与布局三件套 ​

内置组件分类地图 ​

分类代表组件用途
视图容器view scroll-view swiper movable-view布局、滚动区域、轮播、可拖拽元素
基础内容text image icon rich-text progress文本、图片、富文本、进度条
表单button input textarea picker switch slider checkbox radio form数据录入
导航navigator 与 uni.navigateTo 等 API页面跳转（模块 5 细讲）
媒体/地图/画布video audio(已废弃,用 API) map canvas web-view重能力组件
开放能力button open-type分享、登录、授权等平台开放能力

view、text、image 的纪律 ​

  • 布局一律 view。div/span 在小程序端不认识，即便 H5 能跑也不要用。
  • 可选中/可长按的文字必须用 text，view 内文字在部分平台无法长按复制。
  • image 默认有固定宽高（320×240px）且默认 scaleToFill 拉伸，几乎总是要显式写：
vue
<image
  class="avatar"
  src="/static/logo.png"
  mode="aspectFill"
  lazy-load
></image>

常用 mode：aspectFill（等比填满裁剪，头像首选）、aspectFit（等比完整显示）、widthFix（宽度撑满、高度自适应，长图文首选）。

布局三件套：Flex + rpx + scroll-view ​

1) Flex 是跨端最稳的布局 ​

vue
<template>
  <view class="page">
    <view class="navbar">
      <text class="title">消息</text>
      <view class="badge">3</view>
    </view>
    <scroll-view scroll-y class="list" @scrolltolower="loadMore">
      <view v-for="item in list" :key="item.id" class="item">
        <text>{{ item.name }}</text>
      </view>
    </scroll-view>
  </view>
</template>

<script setup lang="ts">
import { ref } from 'vue'

interface Row { id: number; name: string }
const list = ref<Row[]>(Array.from({ length: 20 }, (_, i) => ({ id: i + 1, name: `会话 ${i + 1}` })))

function loadMore() {
  const start = list.value.length
  list.value.push(...Array.from({ length: 20 }, (_, i) => ({ id: start + i + 1, name: `会话 ${start + i + 1}` })))
}
</script>

<style scoped>
.page {
  display: flex;
  flex-direction: column;
  height: 100vh;
}
.navbar {
  display: flex;
  align-items: center;
  justify-content: space-between;
  padding: 0 32rpx;
  height: 88rpx;
  background: #fff;
}
.badge {
  min-width: 36rpx;
  height: 36rpx;
  padding: 0 10rpx;
  line-height: 36rpx;
  text-align: center;
  font-size: 22rpx;
  color: #fff;
  background: #ef4444;
  border-radius: 999rpx;
}
.list {
  flex: 1;
}
.item {
  padding: 28rpx 32rpx;
  border-bottom: 1rpx solid #eef2f8;
}
</style>

注意：scroll-view 滚动需要明确高度。整页滚动通常不用 scroll-view（直接用页面滚动），只有局部滚动列表才用它。

2) rpx：750 份的屏宽哲学 ​

750rpx 恒等于屏幕宽度。375px 设计稿下 1rpx = 0.5px；在更宽/更窄的设备上整体等比缩放。下面的演练场可切换设备宽度直观感受：

使用建议：

  • 尺寸、间距、字号用 rpx，保证多设备一致。
  • 1rpx 边框是常见写法（高分屏细线）；但在部分 H5 超宽屏会被放大，可接受或改用 px。
  • 需要物理一致的小尺寸（如图标描边）可混用 px。

3) 安全区适配 ​

全面屏底部横条会挡住内容，使用安全区变量：

css
.safe-bottom {
  padding-bottom: constant(safe-area-inset-bottom); /* iOS 老语法 */
  padding-bottom: env(safe-area-inset-bottom);
}

scroll-view 开启 safe-area-inset-bottom 属性也可自动处理；小程序端在 pages.json 中可配置 navigationStyle: custom 后自行处理顶部状态栏高度（uni.getWindowInfo().statusBarHeight）。

表单组件的两个坑 ​

数据绑定与事件名差异 ​

vue
<input :value="keyword" @input="onInput" placeholder="搜索" />
ts
function onInput(e: { detail: { value: string } }) {
  keyword.value = e.detail.value // 小程序的取值路径是 e.detail.value，不是 e.target.value
}

可以直接用 v-model="keyword"（uni-app Vue3 版已对表单组件做了双向绑定适配，编译期处理差异），但要理解底层取值路径，调试事件对象时不会懵。

picker 是声明式的 ​

vue
<picker mode="selector" :range="categories" @change="onPick">
  <view class="picker">{{ categories[index] || '请选择分类' }}</view>
</picker>
ts
const categories = ['电子产品', '服饰', '食品']
const index = ref(0)
function onPick(e: { detail: { value: string } }) {
  index.value = Number(e.detail.value)
}

跨端样式注意清单 ​

  1. 小程序支持的选择器有限：类选择器为主，少用后代层级过深的选择器、属性选择器和 *。
  2. 背景图：本地图片在小程序端不支持 background-image: url(本地路径)，要么用 <image>，要么用网络图片/base64。
  3. 字体：自定义字体在小程序需要走 uni.loadFontFace，且字体文件需 HTTPS 地址。
  4. position: fixed 相对的是小程序页面视口，键盘弹起时表现与 H5 不同，表单页务必真机验证。
  5. 不支持的 CSS（如部分滤镜、混合模式）在小程序端静默失效，设计阶段就要核对。

常见问题 ​

Q：swiper 高度为什么不生效？swiper 默认高度 150px 且不会被内容撑开，必须显式设置高度（rpx 或计算值）。

Q：图片在小程序不显示？ 按顺序排查：路径是否在 src/static 或正确的 CDN 地址；域名是否配置合法域名；mode 与容器高度是否为 0。

Q：长列表用 scroll-view 还是页面滚动？ 整页列表用页面滚动 + 生命周期 onReachBottom；嵌在固定布局中的局部列表用 scroll-view + @scrolltolower。超长列表（上千行）参考 8.2 虚拟列表。
