3.3 实战案例：封装跨端 UI 组件库基础件 ​

本篇产出四个后续实战模块会反复使用的基础组件。目标不是重造 uni-ui，而是掌握封装范式：以后任何设计规范落地都能照此办理。

统一设计变量 ​

src/uni.scss（全局变量，需在组件中 @import '@/uni.scss'; 或通过 vite 注入）：

scss
$brand: #2b7fff;
$brand-light: #eaf2ff;
$danger: #ef4444;
$text-1: #1f2937;
$text-2: #64748b;
$radius: 16rpx;

组件一：uni-button（类型/尺寸/禁用/加载） ​

vue
<!-- components/uni-button/uni-button.vue -->
<template>
  <button
    class="u-btn"
    :class="[`u-btn--${type}`, `u-btn--${size}`, { 'is-disabled': disabled || loading }]"
    :disabled="disabled || loading"
    :hover-class="disabled || loading ? '' : 'u-btn--hover'"
    @tap="onTap"
  >
    <text v-if="loading" class="u-btn__spinner" />
    <slot />
  </button>
</template>

<script setup lang="ts">
withDefaults(
  defineProps<{
    type?: 'primary' | 'secondary' | 'danger'
    size?: 'sm' | 'md' | 'lg'
    disabled?: boolean
    loading?: boolean
  }>(),
  { type: 'primary', size: 'md', disabled: false, loading: false }
)

const emit = defineEmits<{ tap: [] }>()
function onTap() {
  emit('tap')
}
</script>

<style lang="scss" scoped>
.u-btn {
  display: inline-flex;
  align-items: center;
  justify-content: center;
  gap: 12rpx;
  border-radius: $radius;
  font-weight: 600;
  border: 0;
}
.u-btn--md { padding: 0 40rpx; height: 80rpx; font-size: 28rpx; }
.u-btn--sm { padding: 0 24rpx; height: 60rpx; font-size: 24rpx; }
.u-btn--lg { width: 100%; height: 88rpx; font-size: 30rpx; }
.u-btn--primary { background: $brand; color: #fff; }
.u-btn--secondary { background: $brand-light; color: $brand; }
.u-btn--danger { background: $danger; color: #fff; }
.u-btn--hover { opacity: 0.85; }
.is-disabled { opacity: 0.5; }
.u-btn__spinner {
  width: 24rpx;
  height: 24rpx;
  border: 3rpx solid rgba(255, 255, 255, 0.4);
  border-top-color: #fff;
  border-radius: 50%;
  animation: u-spin 0.7s linear infinite;
}
@keyframes u-spin {
  to { transform: rotate(360deg); }
}
</style>

WARNING

小程序的原生 button 自带边框、内边距与默认样式，封装时要用 button::after { border: 0 } 清掉自带边框；hover-class 是跨端做按压反馈最稳的方式，CSS :active 在部分平台不可靠。

组件二：uni-card（标题插槽 + 内容插槽 + 底部插槽） ​

vue
<!-- components/uni-card/uni-card.vue -->
<template>
  <view class="u-card">
    <view v-if="$slots.title || title" class="u-card__header">
      <slot name="title"><text class="u-card__title">{{ title }}</text></slot>
      <view class="u-card__extra"><slot name="extra" /></view>
    </view>
    <view class="u-card__body"><slot /></view>
    <view v-if="$slots.footer" class="u-card__footer"><slot name="footer" /></view>
  </view>
</template>

<script setup lang="ts">
defineProps<{ title?: string }>()
</script>

<style lang="scss" scoped>
.u-card {
  background: #fff;
  border-radius: 20rpx;
  padding: 28rpx;
  margin: 20rpx 24rpx;
  box-shadow: 0 8rpx 24rpx rgba(31, 41, 55, 0.05);
}
.u-card__header {
  display: flex;
  align-items: center;
  justify-content: space-between;
  margin-bottom: 20rpx;
}
.u-card__title { font-size: 32rpx; font-weight: 700; color: $text-1; }
.u-card__body { font-size: 28rpx; color: $text-1; line-height: 1.7; }
.u-card__footer { margin-top: 20rpx; padding-top: 20rpx; border-top: 1rpx solid #f1f5f9; }
</style>

使用：

vue
<uni-card>
  <template #title><text>配送地址</text></template>
  <template #extra><uni-button size="sm" type="secondary">修改</uni-button></template>
  <text>北京市朝阳区 uni-app 大厦 9 层</text>
</uni-card>

组件三：empty-state（空状态） ​

vue
<!-- components/empty-state/empty-state.vue -->
<template>
  <view class="u-empty">

    <text class="u-empty__text">{{ text }}</text>
    <view v-if="$slots.action" class="u-empty__action"><slot name="action" /></view>

组件四：list-cell（左文右值的标准列表行） ​

vue
<!-- components/list-cell/list-cell.vue -->
<template>
  <view class="u-cell" hover-class="u-cell--hover" @tap="$emit('tap')">
    <view class="u-cell__left">
      <text v-if="label" class="u-cell__label">{{ label }}</text>
      <slot name="left" />
    </view>
    <view class="u-cell__right">
      <text v-if="value" class="u-cell__value" :class="{ 'is-placeholder': !value }">
        {{ value || placeholder }}
      </text>
      <slot name="right" />
      <text v-if="arrow" class="u-cell__arrow">›</text>
    </view>
  </view>
</template>

<script setup lang="ts">
withDefaults(
  defineProps<{
    label?: string
    value?: string
    placeholder?: string
    arrow?: boolean
  }>(),
  { label: '', value: '', placeholder: '请选择', arrow: true }
)
defineEmits<{ tap: [] }>()
</script>

<style lang="scss" scoped>
.u-cell {
  display: flex;
  align-items: center;
  justify-content: space-between;
  min-height: 96rpx;
  padding: 0 32rpx;
  background: #fff;
  border-bottom: 1rpx solid #f1f5f9;
}
.u-cell--hover { background: #f8fafc; }
.u-cell__label { font-size: 28rpx; color: $text-1; }
.u-cell__right { display: flex; align-items: center; gap: 12rpx; }
.u-cell__value { font-size: 28rpx; color: $text-1; }
.is-placeholder { color: #94a3b8; }
.u-cell__arrow { color: #cbd5e1; font-size: 36rpx; }
</style>

验收清单 ​

完成后逐项在 H5 与微信小程序两端检查：

  • [ ] 按钮的点击、禁用、加载状态在两端表现一致
  • [ ] 所有尺寸使用 rpx，320px 与 414px 设备无错位
  • [ ] 卡片插槽可自由组合，无插槽区域不渲染空白头/尾（用 $slots 判断）
  • [ ] 组件在深色业务背景下无穿透样式问题（scoped 生效）
  • [ ] 未 import 即可使用（easycom 生效）
  • [ ] TS 下传错 prop 类型能在编辑器报红

练习 ​

  1. 给 uni-button 增加 block（通栏）与 round（胶囊）两个布尔 prop。
  2. 用 list-cell + picker 组合一个「表单项」组件 form-picker，支持 v-model。
  3. 把四个组件抽到独立 git 分支，尝试发布到你们的私有 npm（组件库工程化的第一步）。
