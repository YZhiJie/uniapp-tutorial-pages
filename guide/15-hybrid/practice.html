15.3 实战案例：三种典型混合栈架构落地 ​

学习目标 ​

读完本章，你应该能动手搭建以下三套混合栈架构中的任意一套，并且代码可以直接放进项目跑：

  1. 方案 A：uni-app App 内嵌高德地图 3D SDK（requireNativePlugin 完整链路）。
  2. 方案 B：uni-app 小程序 + 独立 Vue 3 H5 编辑器（postMessage 双向同步）。
  3. 方案 C：H5 + 小程序 + App 三端统一登录态（unionid + JWT + cookie 同步全流程）。

每套方案都包含：目录结构 → 配置 → 完整可运行代码 → 常见坑。

方案 A：uni-app App + 原生 AMap 3D SDK ​

适用场景 ​

你的 App 需要高德地图 3D 引擎的原生能力（3D 建筑物渲染、室内地图、步行实景导航、自定义 Marker 动画），JS 端 <map> 组件满足不了。接入后，App 端的地图性能和原生 App 完全一致。

Step 1：HBuilderX 插件市场一键集成（推荐） ​

90% 的项目用这一招就够了——不用手动下载 .aar / .framework。

  1. 打开 HBuilderX → 你的 uni-app 项目。
  2. 菜单：工具 → 制作自定义调试基座（先准备打包环境）。
  3. 菜单：视图 → 显示内置插件市场。
  4. 搜索「高德地图 3D」→ 点击「使用 HBuilderX 内置版本」→ 填写高德开放平台的 Android Key + iOS Key。
  5. 勾选后，HBuilderX 会自动在 manifest.json 里写入 nativePlugins 节点，自动下载 aar/framework，自动加权限。

Android 原生模块骨架 ​

当插件市场的版本不能直接用时，你需要写一个 WXModule 来桥接。

java
// nativeplugins/AMap3D/android/src/main/java/com/yourcompany/amap/AMap3DModule.java
package com.yourcompany.amap;

import com.taobao.weex.annotation.JSMethod;
import com.taobao.weex.bridge.JSCallback;
import com.taobao.weex.common.WXModule;

import com.amap.api.mapcore.util.ScreenUtils;
import com.amap.api.maps.AMap;
import com.amap.api.maps.CameraUpdateFactory;
import com.amap.api.maps.MapView;
import com.amap.api.maps.MapsInitializer;
import com.amap.api.maps.model.LatLng;
import com.amap.api.maps.model.Marker;
import com.amap.api.maps.model.MarkerOptions;
import com.amap.api.location.AMapLocationClient;
import com.amap.api.location.AMapLocationListener;
import com.amap.api.location.AMapLocation;

import android.content.Context;
import android.util.Log;
import android.widget.FrameLayout;

import java.util.HashMap;
import java.util.Map;

public class AMap3DModule extends WXModule {

    private static AMapLocationClient locationClient;

    /**
     * uni.requireNativePlugin('AMap3D').init({...}, callback)
     * 初始化 SDK，必须在第一次使用地图前调用
     */
    @JSMethod(uiThread = false)
    public void init(Map<String, Object> options, JSCallback callback) {
        Context ctx = mWXSDKInstance.getContext().getApplicationContext();
        try {
            // 高德 Android 端 Key 必须在 Application.onCreate 或最早时机设置
            String mapKey = (String) options.getOrDefault("androidKey", "");
            MapsInitializer.updatePrivacyShow(ctx, true, true);
            MapsInitializer.setApiKey(mapKey);

            if (locationClient == null) {
                locationClient = new AMapLocationClient(ctx);
            }
            callback.invokeAndKeepAlive(makeResult(0, "ok"));
        } catch (Exception e) {
            callback.invoke(makeResult(-1, e.getMessage()));
        }
    }

    /**
     * uni.requireNativePlugin('AMap3D').getCurrentLocation({}, callback)
     * 单次定位
     */
    @JSMethod(uiThread = false)
    public void getCurrentLocation(Map<String, Object> options, JSCallback callback) {
        if (locationClient == null) {
            callback.invoke(makeResult(-1, "请先调用 init"));
            return;
        }

        AMapLocationListener listener = location -> {
            if (location != null && location.getErrorCode() == 0) {
                Map<String, Object> data = new HashMap<>();
                data.put("latitude", location.getLatitude());
                data.put("longitude", location.getLongitude());
                data.put("address", location.getAddress());
                data.put("province", location.getProvince());
                data.put("city", location.getCity());
                data.put("district", location.getDistrict());
                callback.invoke(makeResultData(0, "ok", data));
            } else {
                callback.invoke(makeResult(-1, location != null ? location.getErrorInfo() : "定位失败"));
            }
        };

        locationClient.setLocationListener(listener);
        locationClient.startLocation();
        // 单次定位后停止
        locationClient.stopLocation();
    }

    // ===== 工具方法 =====
    private Map<String, Object> makeResult(int code, String msg) {
        Map<String, Object> r = new HashMap<>();
        r.put("code", code);
        r.put("message", msg);
        return r;
    }

    private Map<String, Object> makeResultData(int code, String msg, Object data) {
        Map<String, Object> r = makeResult(code, msg);
        r.put("data", data);
        return r;
    }
}

Step 3：JS 桥接层（生产级） ​

ts
// src/services/amap-native.ts
/**
 * 高德地图 3D JS 桥接层
 * - App 端调用原生 AMap3DModule
 * - 小程序 / H5 端降级：小程序用腾讯地图 API，H5 用高德 JS API
 */

type Platform = 'app' | 'mp-weixin' | 'h5'

interface InitOptions {
  androidKey?: string
  iosKey?: string
}

interface LocationResult {
  latitude: number
  longitude: number
  address: string
  province: string
  city: string
  district: string
}

// 环境检测
function detectPlatform(): Platform {
  // #ifdef APP-PLUS
  return 'app'
  // #endif
  // #ifdef MP-WEIXIN
  return 'mp-weixin'
  // #endif
  return 'h5'
}

// ===== App 端原生插件 =====
// #ifdef APP-PLUS
const nativeAMap = uni.requireNativePlugin('AMap3D')
// #endif

export const AMap3DService = {
  private inited = false,

  async init(options: InitOptions): Promise<void> {
    const platform = detectPlatform()

    if (platform === 'app') {
      await new Promise<void>((resolve, reject) => {
        nativeAMap.init(options, (res: { code: number; message: string }) => {
          if (res.code === 0) {
            this.inited = true
            resolve()
          } else {
            reject(new Error(res.message))
          }
        })
      })
    }

    this.inited = true
  },

  /** 单次定位 */
  getCurrentLocation(): Promise<LocationResult> {
    const platform = detectPlatform()

    return new Promise((resolve, reject) => {
      if (platform === 'app') {
        // #ifdef APP-PLUS
        nativeAMap.getCurrentLocation({}, (res: any) => {
          if (res.code === 0) resolve(res.data)
          else reject(new Error(res.message))
        })
        // #endif
      } else if (platform === 'mp-weixin') {
        // 小程序降级：腾讯地图
        uni.getLocation({
          type: 'gcj02',
          success: async (r) => {
            // 再用腾讯地图 API 做逆地理编码
            const { data } = await uni.request({
              url: `https://apis.map.qq.com/ws/geocoder/v1/?location=${r.latitude},${r.longitude}&key=${TENCENT_MAP_KEY}`,
            })
            resolve({
              latitude: r.latitude,
              longitude: r.longitude,
              address: data?.result?.address ?? '',
              province: data?.result?.address_component?.province ?? '',
              city: data?.result?.address_component?.city ?? '',
              district: data?.result?.address_component?.district ?? '',
            })
          },
          fail: reject,
        })
      } else {
        // H5 降级：高德 JS API
        reject(new Error('H5 端请直接使用高德 JS API'))
      }
    })
  },
}

Step 1：H5 侧桥接层 ​

ts
// h5-editor/src/bridge/mp-bridge.ts
/**
 * 小程序 web-view → H5 双向通信桥
 * H5 是被加载方，小程序是宿主
 */

type MsgHandler = (payload: any) => void

// ========== 环境检测 ==========
export function isInMiniProgram(): boolean {
  // 微信 web-view 会注入 __wxjs_environment
  return window.__wxjs_environment === 'miniprogram' ||
    /miniProgram/i.test(navigator.userAgent)
}

export function getMPSDK(): any {
  return (window as any).wx?.miniProgram
}

// ========== H5 → 小程序 ==========

/**
 * 向小程序宿主发消息
 * 小程序端通过 <web-view @message> 接收
 * 注意：微信 postMessage 只在 后退/分享/销毁 时触发
 * 所以我们同时配合 navigateTo 带 payload 做实时触发
 */
export function sendToMiniProgram(type: string, data: any = {}) {
  if (!isInMiniProgram()) return

  const payload = {
    type,
    data,
    ts: Date.now(),
    source: 'h5-editor',
  }

  const mp = getMPSDK()
  if (!mp) return

  // 方式一：postMessage（小程序在特定时机收到）
  mp.postMessage({ data: payload })

  // 方式二：navigateTo 携带 payload（实时触发小程序逻辑）
  // 小程序需要有一个 callback 页面来处理，或者把 payload 写入 localStorage
  // 让宿主在 onShow 时主动拉取
  try {
    const encoded = encodeURIComponent(JSON.stringify(payload))
    // 写到 H5 的 localStorage，然后小程序通过 URL 参数或轮询拉取
    localStorage.setItem('__mp_pending_message', JSON.stringify(payload))
  } catch {
    // localStorage 可能受限
  }
}

/**
 * 主动触发小程序刷新（通过 URL 变化 + reload key）
 */
export function triggerMiniProgramReload(reason: string) {
  if (!isInMiniProgram()) return
  try {
    localStorage.setItem('__mp_reload', reason)
  } catch { /* ignore */ }
}

/**
 * 拉起另一个小程序（需要 wx-open-launch-weapp 在小程序端配置）
 */
export function launchOtherMiniProgram(appId: string, path: string) {
  const mp = getMPSDK()
  mp?.navigateToMiniProgram?.({ appId, path })
}

// ========== 小程序 → H5 ==========

/**
 * 注册一个全局函数，小程序宿主可以通过 evalJS 调用
 * 比如 plus.webview.evalJS("window.__H5_ON_MESSAGE__(...)")
 */
export function setupMessageReceiver() {
  // 被小程序宿主 evalJS 调用的入口
  ;(window as any).__H5_ON_MESSAGE__ = (payload: any) => {
    const handler = receivers.get(payload?.type ?? '*')
    if (handler) handler(payload.data ?? payload)
    else console.warn('[H5 Bridge] 未处理消息:', payload)
  }
}

const receivers = new Map<string, MsgHandler>()

export function onMPMessage(type: string, handler: MsgHandler) {
  receivers.set(type, handler)
  // 如果小程序在 H5 打开前就已经通过 URL query 注入了参数，在这里处理
  const urlParams = new URLSearchParams(location.search)
  const initData = urlParams.get('init')
  if (initData) {
    try {
      const parsed = JSON.parse(decodeURIComponent(initData))
      handler(parsed)
    } catch { /* ignore */ }
  }
}

// ========== 初始化 ==========
export function initBridge() {
  setupMessageReceiver()
  console.log('[H5 Bridge] 初始化完成, env:', isInMiniProgram() ? 'miniProgram' : 'standalone')
}

// uniapp-mini/utils/webview-messager.ts
/**
 * 小程序 web-view 消息管理器
 * 解决 postMessage 消息数组堆积 + 触发时机不确定问题
 */

type Handler = (data: any) => void

interface QueueItem {
  type: string
  data: any
  ts: number
}

const queue: QueueItem[] = []
const handlers = new Map<string, Handler>()

/** feed web-view @message 事件的 raw data */
export function feedMessage(e: { detail: { data: any[] } }) {
  const rawList = e.detail.data ?? []

  // 小程序 web-view 发的消息里，可能有我们 payload 也可能有微信内部消息
  for (const raw of rawList) {
    // 提取 type/data/ts 结构的
    if (raw?.type && raw?.source === 'h5-editor') {
      queue.push({
        type: raw.type,
        data: raw.data,
        ts: raw.ts ?? Date.now(),
      })
    }
  }

  flush()
}

/** 注册消息处理器 */
export function registerMessage(type: string, handler: Handler) {
  handlers.set(type, handler)
  // 如果之前已经有这类消息积压，立即处理
  queue
    .filter(q => q.type === type)
    .forEach(q => handler(q.data))
}

function flush() {
  while (queue.length > 0) {
    const item = queue.shift()!
    const handler = handlers.get(item.type)
    if (handler) {
      try { handler(item.data) }
      catch (e) { console.error('[Messager] handler error:', item.type, e) }
    } else {
      console.warn('[Messager] 未注册的消息:', item.type, item.data)
    }
  }
}

/** 清理过期消息（避免队列无限增长） */
export function cleanup(days = 1) {
  const cutoff = Date.now() - days * 24 * 60 * 60 * 1000
  for (let i = queue.length - 1; i >= 0; i--) {
    if (queue[i].ts < cutoff) queue.splice(i, 1)
  }
}

/** 调试：打印当前队列 */
export function debug() {
  console.log('[Messager] queue:', queue.length, 'handlers:', [...handlers.keys()])
}

常见坑 ​

坑原因解法
postMessage 不触发这是微信设计——只在后退 / 分享 / 销毁时触发配合 wx.miniProgram.navigateTo 或 navigateBackMiniProgram 主动触发
URL 长度限制小程序 web-view URL 不能超过 2KB大 payload 不走 URL，走 localStorage + H5 主动轮询（H5 端定时读 storage）
域名白名单小程序后台要配置「业务域名」小程序后台 → 开发管理 → 开发设置 → 业务域名，加 https 域名
编辑器闪白web-view 首次加载 H5 体积大H5 项目做资源预加载：vite-plugin-preload + suspense lazy import
双向通信延迟postMessage 非实时设计成「最终一致性」：H5 做本地缓存 + 定时同步；小程序不追求每次 keystroke 都同步

方案 C：H5 + 小程序 + App 三端统一登录态 ​

适用场景 ​

一个完整的电商系统：官网 H5、微信小程序、uni-app App。用户可以在任意一端登录，登录态自动同步到另外两端。后端一套 JWT，三端通用。

  mpAppId: process.env.WX_MP_APPID!,
  mpSecret: process.env.WX_MP_SECRET!,
  appAppId: process.env.WX_APP_APPID!,
  appSecret: process.env.WX_APP_SECRET!,
}
const JWT_SECRET = process.env.JWT_SECRET!
const COOKIE_DOMAIN = process.env.COOKIE_DOMAIN ?? '.your-shop.com'

// ========== 数据层（用假数据演示） ==========
const users: Map<string, any> = new Map()  // key: unionid / phone

// ========== JWT 工具 ==========
interface JWTPayload {
  userId: string
  unionid?: string
  phone?: string
  platform: 'h5' | 'mp' | 'app'
  iat: number
  exp: number
}

function signJWT(user: any, platform: 'h5' | 'mp' | 'app') {
  const payload: Omit<JWTPayload, 'iat' | 'exp'> = {
    userId: user.id,
    unionid: user.unionid,
    phone: user.phone,
    platform,
  }
  return jwt.sign(payload, JWT_SECRET, { expiresIn: '7d' })
}

function verifyJWT(token: string): JWTPayload | null {
  try { return jwt.verify(token, JWT_SECRET) as JWTPayload }
  catch { return null }
}

// ========== 路由 ==========

/**
 * 微信登录（小程序 / App 共用）
 * 前端传 code + platform 区分
 */
app.post('/api/auth/login-by-wx', async (req, res) => {
  const { code, platform } = req.body as { code: string; platform: 'mp' | 'app' }
  if (!code || !platform) return res.status(400).json({ code: 1, msg: '缺少 code' })

  const { mpAppId, mpSecret, appAppId, appSecret } = WX_OPEN
  const appId = platform === 'mp' ? mpAppId : appAppId
  const secret = platform === 'mp' ? mpSecret : appSecret

  // 1. code 换 openid + unionid
  const wxRes = await axios.get(
    'https://api.weixin.qq.com/sns/jscode2session',
    { params: { appid: appId, secret, js_code: code, grant_type: 'authorization_code' } }
  )

  const { openid, unionid, errcode, errmsg } = wxRes.data
  if (errcode) return res.status(400).json({ code: 1, msg: `微信错误 ${errcode}: ${errmsg}` })

  // 2. 查找或创建用户（unionid 优先，openid 其次）
  let user = users.get(unionid)
  if (!user) {
    // 用 openid 找（可能之前只在一端登录，还没 unionid）
    for (const u of users.values()) {
      if ((platform === 'mp' && u.openid_mp === openid) ||
          (platform === 'app' && u.openid_app === openid)) {
        user = u
        break
      }
    }
  }

  if (!user) {
    // 全新用户
    user = {
      id: `u_${Date.now()}`,
      unionid: unionid ?? null,
      openid_mp: platform === 'mp' ? openid : null,
      openid_app: platform === 'app' ? openid : null,
      phone: null,
      createdAt: Date.now(),
    }
  } else {
    // 补齐 openid（延迟关联 unionid 场景）
    if (platform === 'mp' && user.openid_mp !== openid) user.openid_mp = openid
    if (platform === 'app' && user.openid_app !== openid) user.openid_app = openid
    if (unionid) user.unionid = unionid
  }
  users.set(user.unionid ?? user.id, user)

  // 3. 签发 JWT
  const token = signJWT(user, platform)

  res.json({
    code: 0,
    data: {
      token,
      userId: user.id,
      unionid: user.unionid,
      hasPhone: !!user.phone,
      expiresIn: 7 * 24 * 60 * 60,
    },
  })
})

ts
// uniapp-shared/src/auth/jwt-store.ts
/**
 * 三端统一 JWT 管理
 * - App / 小程序：用 uni.storage 存（持久化）
 * - H5：localStorage + HttpOnly Cookie 双通道
 */

const TOKEN_KEY = 'app_token'
const USER_KEY = 'app_user'

interface User {
  userId: string
  unionid?: string
  phone?: string
  platform: string
}

export const JWTStore = {
  getToken(): string {
    // #ifdef H5
    return localStorage.getItem(TOKEN_KEY) ?? ''
    // #endif
    // #ifndef H5
    return uni.getStorageSync(TOKEN_KEY) ?? ''
    // #endif
  },

  setToken(token: string) {
    // #ifdef H5
    localStorage.setItem(TOKEN_KEY, token)
    // H5 同时需要让后端把 token 写到 HttpOnly Cookie
    // 这样 axios withCredentials 时会自动带上
    fetch(`${BASE_URL}/api/auth/set-cookie`, {
      method: 'POST',
      credentials: 'include',
      headers: { 'Content-Type': 'application/json' },
      body: JSON.stringify({ token }),
    })
    // #endif
    // #ifndef H5
    uni.setStorageSync(TOKEN_KEY, token)
    // #endif
  },

  clearToken() {
    // #ifdef H5
    localStorage.removeItem(TOKEN_KEY)
    // #endif
    // #ifndef H5
    uni.removeStorageSync(TOKEN_KEY)
    // #endif
  },

  getUser(): User | null {
    try {
      // #ifdef H5
      return JSON.parse(localStorage.getItem(USER_KEY) ?? 'null')
      // #endif
      // #ifndef H5
      return uni.getStorageSync(USER_KEY) || null
      // #endif
    } catch { return null }
  },

  setUser(user: User) {
    // #ifdef H5
    localStorage.setItem(USER_KEY, JSON.stringify(user))
    // #endif
    // #ifndef H5
    uni.setStorageSync(USER_KEY, user)
    // #endif
  },

  /**
   * 被其他端拉起来时，从 URL query 里提取 JWT 并自动登录
   * 场景：App 启动 H5 活动页时，H5 URL 带 ?jwt=xxx
   */
  hydrateFromURL(): boolean {
    // #ifdef H5
    const urlParams = new URLSearchParams(location.search)
    const jwt = urlParams.get('jwt')
    if (!jwt) return false

    this.setToken(jwt)

    // 从 JWT payload 里解出 user（不依赖后端）
    try {
      const payload = JSON.parse(atob(jwt.split('.')[1]))
      this.setUser({
        userId: payload.userId,
        unionid: payload.unionid,
        phone: payload.phone,
        platform: payload.platform,
      })
    } catch { /* ignore */ }

    // 清理 URL
    history.replaceState({}, '', location.pathname)
    return true
    // #endif
    return false
  },

  logout() {
    this.clearToken()
    // #ifdef H5
    localStorage.removeItem(USER_KEY)
    // 让后端清 cookie
    fetch(`${BASE_URL}/api/auth/logout`, { method: 'POST', credentials: 'include' })
    // #endif
    // #ifndef H5
    uni.removeStorageSync(USER_KEY)
    // #endif
  },
}

ts
// uniapp-mini/src/services/auth.ts
import { JWTStore } from './auth/jwt-store'

const BASE_URL = 'https://api.your-shop.com'

/** 微信登录（小程序 / App 端都适用） */
export async function wxLogin(): Promise<void> {
  const platform = detectPlatform()  // 'mp-weixin' | 'app'

  // 1. uni.login 内部会调微信 SDK / JSSDK 拿到 code
  const { code } = await new Promise<{ code: string }>((resolve, reject) => {
    uni.login({ provider: 'weixin', success: resolve, fail: reject })
  })

  // 2. 发给后端换 JWT
  const { data } = await uni.request({
    url: `${BASE_URL}/api/auth/login-by-wx`,
    method: 'POST',
    data: { code, platform },
  })

  if (data.code !== 0) throw new Error(data.msg)

  // 3. 存 token + user
  JWTStore.setToken(data.data.token)
  JWTStore.setUser({
    userId: data.data.userId,
    unionid: data.data.unionid,
    platform,
  })
}

function detectPlatform(): 'mp-weixin' | 'app' {
  // #ifdef MP-WEIXIN
  return 'mp-weixin'
  // #endif
  return 'app'
}

Step 4：打开 H5 时同步登录态 ​

这是整个「三端统一」里最关键的一步——App / 小程序 打开一个需要登录的 H5 页面时，必须把 JWT 带过去。

小程序里打开 H5（web-view） ​

vue
<!-- pages/activity/activity.vue -->
<template>
  <view>
    <web-view :src="h5Url" />
  </view>
</template>

<script setup>
import { computed } from 'vue'
import { JWTStore } from '@/auth/jwt-store'

const h5Url = computed(() => {
  const base = 'https://www.your-shop.com/activity/double11'
  const token = JWTStore.getToken()
  // H5 侧用 JWTStore.hydrateFromURL() 提取
  return token ? `${base}?jwt=${encodeURIComponent(token)}` : base
})
</script>

App 里打开 H5（plus.webview） ​

js
// #ifdef APP-PLUS
import { JWTStore } from '@/auth/jwt-store'

const token = JWTStore.getToken()
const url = token
  ? `https://www.your-shop.com/activity/double11?jwt=${encodeURIComponent(token)}`
  : 'https://www.your-shop.com/activity/double11'

const webview = plus.webview.create(url, 'h5-activity', { top: '88px' })
plus.webview.currentWebview().append(webview)
// #endif

H5 入口自动读取 ​

ts
// h5-shop/src/main.ts
import { JWTStore } from '@/auth/jwt-store'
import App from './App.vue'

// 启动时检查 URL 里有没有 jwt 参数
const hydrated = JWTStore.hydrateFromURL()

createApp(App).mount('#app')

Step 5：请求拦截器（三端通吃） ​

ts
// uniapp-shared/src/request.ts
import { JWTStore } from './auth/jwt-store'

const BASE_URL = 'https://api.your-shop.com'

export const request = (() => {
  // axios 实例（H5 用）
  // uni.request（小程序 / App 用）
  return async function(options: UniApp.RequestOptions | RequestInit) {
    const token = JWTStore.getToken()

    // #ifdef H5
    return fetch(`${BASE_URL}${options.url}`, {
      ...options,
      credentials: 'include',    // cookie 自动带
      headers: {
        'Content-Type': 'application/json',
        ...(token ? { Authorization: `Bearer ${token}` } : {}),
        ...(options.headers as any ?? {}),
      },
    }).then(r => r.json())
    // #endif

    // #ifndef H5
    return uni.request({
      url: `${BASE_URL}${options.url}`,
      ...options,
      header: {
        'Content-Type': 'application/json',
        ...(token ? { Authorization: `Bearer ${token}` } : {}),
        ...(options.header ?? {}),
      },
    })
    // #endif
  }
})()

常见坑与解决 ​

坑原因解法
Cookie 在 H5 和小程序/App 之间不共享完全不同的容器，Cookie 本就不互通App / 小程序 打开 H5 时 URL 带 ?jwt=xxx，H5 启动时 hydrateFromURL
unionid 返回 null微信用户没关注公众号/没登录过同开放平台下的 App后端做延迟关联：先存 openid，下次拿到 unionid 再合并
跨域预检（CORS）失败小程序和 App 虽然不走浏览器 CORS，但 H5 会走后端 CORS 配置 credentials: true + 精确 origins（不能 *）
H5 Cookie 被浏览器阻止SameSite 策略JWT 同时放 Authorization header 和 Cookie；Cookie 设 SameSite=Lax; Secure
JWT 过期后静默失败小程序 / App 没有自动跳登录请求拦截器里统一处理 401：清 token → 触发全局登录事件 → 跳转登录页

三方案横向对比 ​

维度方案 A：App + 原生 SDK方案 B：小程序 + 独立 H5 编辑器方案 C：三端统一登录
混合类型requireNativePlugin（App 端专属）web-view（小程序 + App）账号体系跨容器互通
通信方向JS → 原生 单向（原生回调 JS）H5 ↔ 小程序 双向（postMessage）App/小程序 → H5 单向（URL jwt）
核心难点原生 SDK 集成、WXModule 写 Java/Swift微信 postMessage 非实时、域名白名单unionid 关联、Cookie + JWT 双通道
上线门槛需要原生 SDK + 云打包 / 原生工程纯 H5 + uni-app 小程序壳需要一套稳定的后端 Auth 服务
适合阶段App 已经要上生产、需要高性能原生模块编辑器/活动页等需要独立迭代的场景产品要做完整生态闭环
典型工作量3–5 天（插件市场一键集成）/ 1–2 周（手写插件）1 周（H5 侧 + 小程序承载页）1–2 周（后端 Auth + 三端前端适配）
