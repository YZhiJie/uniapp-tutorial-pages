5.1 基础入门：pages.json 与页面栈五件套 ​

uni-app 没有 vue-router：路由由 pages.json 静态注册 + 页面栈 API 管理（这样才能编译到小程序）。

pages.json 基础结构 ​

jsonc
{
  "pages": [
    {
      "path": "pages/index/index",
      "style": {
        "navigationBarTitleText": "首页",
        "enablePullDownRefresh": true,
        "backgroundColor": "#f4f6fa"
      }
    },
    {
      "path": "pages/goods/list",
      "style": { "navigationBarTitleText": "商品列表" }
    }
  ],
  "globalStyle": {
    "navigationBarTextStyle": "black",
    "navigationBarBackgroundColor": "#ffffff",
    "backgroundColor": "#f4f6fa"
  },
  "tabBar": {
    "color": "#94a3b8",
    "selectedColor": "#2b7fff",
    "backgroundColor": "#ffffff",
    "list": [
      { "pagePath": "pages/index/index", "text": "首页", "iconPath": "static/tab/home.png", "selectedIconPath": "static/tab/home-on.png" },
      { "pagePath": "pages/cart/index", "text": "购物车", "iconPath": "static/tab/cart.png", "selectedIconPath": "static/tab/cart-on.png" },
      { "pagePath": "pages/mine/index", "text": "我的", "iconPath": "static/tab/mine.png", "selectedIconPath": "static/tab/mine-on.png" }
    ]
  }
}

铁律：

  1. pages 数组第一项是应用启动页。
  2. 任何页面必须先注册才能跳转，新增页面忘注册是最高频错误。
  3. tabBar 页面（2–5 个）必须都在 pages 中注册，图标用本地静态图片。

页面栈：五个跳转 API 的本质区别 ​

API行为栈变化典型用途
uni.navigateTo保留当前页，压入新页+1（上限 10 层）列表 → 详情
uni.redirectTo关闭当前页，替换为新页不变表单提交后跳结果页
uni.reLaunch清空栈，打开新页变为 1 层退出登录、切换身份
uni.switchTab跳 tabBar 页，关闭所有非 tab 页特殊底部导航切换
uni.navigateBack弹出一层（可跳多层）-n返回、关闭弹窗页
ts
// 列表页跳详情并携带参数
uni.navigateTo({
  url: '/pages/goods/detail?id=1024&from=list'
})

// 详情页返回并提示
uni.navigateBack({ delta: 1 })

// tabBar 页必须用 switchTab，navigateTo 会失败
uni.switchTab({ url: '/pages/cart/index' })

// 登录成功后清空历史
uni.reLaunch({ url: '/pages/index/index' })

目标页接收参数：onLoad ​

vue
<script setup lang="ts">
import { ref } from 'vue'
import { onLoad } from '@dcloudio/uni-app'

const id = ref(0)
const from = ref('')

onLoad((query) => {
  id.value = Number(query?.id)
  from.value = String(query?.from ?? '')
  // 在这里发起详情请求
})
</script>

参数都在 URL query 上，只能传可序列化的短数据（数字、短字符串）。大对象请传 id，由目标页从 store/缓存取，不要把 JSON 塞进 URL。

页面样式配置（style）常用项 ​

字段作用
navigationBarTitleText导航栏标题
navigationStyle: 'custom'自定义导航栏（需自绘状态栏占位）
enablePullDownRefresh开启下拉刷新（配合 onPullDownRefresh）
onReachBottomDistance上拉触底距离（配合 onReachBottom）
backgroundColorTop/Bottom回弹区域颜色（iOS）
disableScroll禁止页面滚动（慎用）

页面生命周期（从 @dcloudio/uni-app 导入，在 <script setup> 中调用）：

  • onLoad(query)：加载（只一次，可取参数）
  • onShow：显示（每次返回该页都会触发，常用于刷新数据）
  • onReady：首次渲染完成
  • onHide：被覆盖
  • onUnload：出栈销毁（清理定时器/请求）
  • onPullDownRefresh / onReachBottom / onShareAppMessage
ts
import { onShow, onUnload } from '@dcloudio/uni-app'

onShow(() => {
  // 从详情页返回时刷新角标等
  refreshCartCount()
})

onUnload(() => {
  timer && clearInterval(timer)
})

分包：pages 之外的页面 ​

主包体积影响启动速度，页面多了必须分包：

jsonc
{
  "pages": [{ "path": "pages/index/index" }],
  "subPackages": [
    {
      "root": "pages/order",
      "pages": [
        { "path": "confirm", "style": { "navigationBarTitleText": "确认订单" } },
        { "path": "list", "style": { "navigationBarTitleText": "订单列表" } }
      ]
    }
  ]
}

跳转路径为完整路径：/pages/order/confirm?id=1。分包策略与预下载在 8.2 详解。

常见问题 ​

Q：navigateTo 没反应？ 按顺序排查：路径是否在 pages.json 注册；目标是不是 tabBar 页（必须 switchTab）；页面栈是否已达 10 层（需 redirectTo 替换）。

Q：怎么修改导航栏标题？ 静态用 pages.json；动态用 uni.setNavigationBarTitle({ title })。

Q：页面间怎么传大对象/返回数据？ 正向：URL 只带 id，数据存 Pinia 或 uni.setStorageSync；反向：navigateTo 的 events + eventChannel（5.2 细讲）。

Q：H5 端刷新 404？ H5 是 history/hash 模式问题：静态服务器需把非静态资源回退到 index.html；或配置 hash 路由模式。
