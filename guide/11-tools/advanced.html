11.2 进阶应用：扫码、存储、文件与分享 ​

本篇代码沿用 7.3 的适配层模式：页面只调用统一接口，平台差异关在 platforms 目录内。

一、扫码与结果解析 ​

ts
// src/platforms/scanner/index.ts
export interface ScanResult {
  text: string
  format: string
}

export function scanCode(): Promise<ScanResult> {
  return new Promise((resolve, reject) => {
    uni.scanCode({
      onlyFromCamera: false,
      scanType: ['qrCode', 'barCode'],
      success: (res) => resolve({ text: res.result, format: res.scanType }),
      fail: (err) => reject(new Error(err.errMsg))
    })
  })
}

/** 识别扫码结果类型，决定落地页 */
export function classifyCode(text: string): 'url' | 'wifi' | 'text' {
  if (/^https?:\/\//i.test(text)) return 'url'
  if (/^WIFI:/.test(text)) return 'wifi'
  return 'text'
}

页面：

ts
async function onScan() {
  try {
    const result = await scanCode()
    switch (classifyCode(result.text)) {
      case 'url':
        // #ifdef H5
        window.open(result.text)
        // #endif
        // #ifndef H5
        uni.navigateTo({ url: `/pages/webview/index?url=${encodeURIComponent(result.text)}` })
        // #endif
        break
      default:
        addRecord({ type: 'scan', content: result.text })
    }
  } catch (e) {
    if (!String(e).includes('cancel')) uni.showToast({ title: '扫码失败', icon: 'none' })
  }
}

H5 降级：提供图片上传，后端或本地 JS 库（如 jsqr）解析；入口文案改为「上传二维码图片」。

二、定位打卡 ​

ts
// src/services/checkin.ts
export interface CheckInRecord {
  id: string
  latitude: number
  longitude: number
  address: string
  createdAt: number
}

export async function checkIn(): Promise<CheckInRecord> {
  const { longitude, latitude } = await getCurrentLocation() // 7.3 的适配层
  const address = await reverseGeocode(longitude, latitude)
  const record: CheckInRecord = {
    id: genUuid(),
    latitude,
    longitude,
    address,
    createdAt: Date.now()
  }
  await recordStore.insert(record) // 先写本地
  syncQueue.enqueue({ type: 'checkin', payload: record }) // 有网再同步
  return record
}

坐标系注意（国内项目高频坑）：

  • uni.getLocation 微信端可指定 gcj02（火星坐标，匹配小程序地图）。
  • H5 浏览器拿到的是 WGS84，展示在国内地图前需要转换。
  • 与服务端统一约定一个坐标系入库，边界转换集中在适配层，不要散落在页面。

三、本地存储分层 ​

text
小配置 / token  → uni storage（key-value，1MB/key 限制）
结构化业务数据 → SQLite（App）/ 平台数据库（小程序）/ IndexedDB（H5）
导出文件       → 文件系统（App、小程序沙盒）/ Blob 下载（H5）

统一数据库接口（适配层） ​

ts
// src/services/db/types.ts
export interface RecordRow {
  id: string
  type: string
  content: string
  createdAt: number
  updatedAt: number
  deleted?: boolean
}

export interface LocalDatabase {
  insert(row: RecordRow): Promise<void>
  update(id: string, patch: Partial<RecordRow>): Promise<void>
  remove(id: string): Promise<void>
  list(query: { type?: string; limit: number; offset: number }): Promise<RecordRow[]>
  count(): Promise<number>
}
  • App 端：使用 plus.sqlite 或社区 SQLite 插件实现 LocalDatabase，建索引 (type, createdAt)。
  • H5 端：IndexedDB 实现（思路同本教程站点的 IndexedDB KV 最近阅读）。
  • 小程序端：小数据量直接 storage 分片（如按月份 key），大数据量评估微信「微信同声传译」类插件或云数据库；不要在主线程做大 JSON 解析。

四、导出 CSV / JSON ​

ts
// src/services/export.ts
function toCSV(rows: RecordRow[]): string {
  const header = 'id,type,content,createdAt\n'
  const escape = (v: string) => `"${v.replace(/"/g, '""')}"`
  return (
    header +
    rows.map((r) => [r.id, r.type, escape(r.content), new Date(r.createdAt).toISOString()].join(',')).join('\n')
  )
}

export async function exportRecords(format: 'csv' | 'json') {
  const rows = await recordsRepo.all()
  const content = format === 'csv' ? toCSV(rows) : JSON.stringify(rows, null, 2)
  const filename = `records-${Date.now()}.${format}`

  // #ifdef H5
  const blob = new Blob(['\ufeff' + content], { type: 'text/plain;charset=utf-8' }) // BOM 防 Excel 乱码
  const url = URL.createObjectURL(blob)
  const a = document.createElement('a')
  a.href = url
  a.download = filename
  a.click()
  URL.revokeObjectURL(url)
  // #endif

  // #ifdef MP-WEIXIN
  const fs = uni.getFileSystemManager()
  const path = `${wx.env.USER_DATA_PATH}/${filename}`
  fs.writeFileSync(path, content, 'utf8')
  uni.openDocument({ filePath: path, showMenu: true, fileType: format === 'csv' ? 'csv' : 'json' })
  // #endif

  // #ifdef APP-PLUS
  const fs = uni.getFileSystemManager()
  const path = `${uni.getFileSystemManager().env.USER_DATA_PATH}/${filename}`
  fs.writeFileSync(path, content, 'utf8')
  uni.openDocument({ filePath: path, showMenu: true })
  // #endif
}

五、保存图片与分享 ​

ts
export async function saveImage(url: string) {
  // 先下载到临时路径，再保存相册（需相册权限，7.3 的权限流程）
  const res = await uni.downloadFile({ url })
  await uni.saveImageToPhotosAlbum({ filePath: res.tempFilePath })

}

分享三端策略与代码同 7.1 分享示例。工具类常用的「生成分享海报」是替代方案的王牌：用 canvas 绘制二维码 + 内容，保存图片后用户可分享到任意渠道，绕开平台差异。

六、提醒能力（工具留存关键） ​

  • 小程序：requestSubscribeMessage 一次性订阅，每次完成操作引导订阅一次，服务端在触发点下发。
  • App：UniPush 本地通知可用于精确提醒（也有纯本地通知 API，无服务端依赖）。
  • H5：无可靠通知，降级为页面内提醒 + 邮件/日历订阅。
