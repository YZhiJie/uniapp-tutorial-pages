9.2 进阶应用：核心链路实现 ​

本篇给出主链路的关键代码骨架，省略的 UI 部分按 模块 3 的组件规范补全。

一、商品列表：分页 + 搜索 + 取消旧请求 ​

vue
<!-- pages/goods/list.vue -->
<script setup lang="ts">
import { computed, ref } from 'vue'
import { onLoad, onReachBottom, onPullDownRefresh } from '@dcloudio/uni-app'
import { goodsApi, type GoodsListItem, type GoodsQuery } from '@/api/modules/goods'

const list = ref<GoodsListItem[]>([])
const query = ref<GoodsQuery>({ page: 1, size: 20, keyword: '' })
const total = ref(0)
const loading = ref(false)
let task: UniApp.RequestTask | null = null

const finished = computed(() => list.value.length >= total.value && list.value.length > 0)

onLoad((options) => {
  query.value.category = options?.category
  query.value.keyword = options?.keyword
  load(true)
})

onReachBottom(() => load(false))
onPullDownRefresh(async () => {
  await load(true)
  uni.stopPullDownRefresh()
})

async function load(reset: boolean) {
  if (loading.value) return
  if (!reset && finished.value) return
  loading.value = true
  if (reset) query.value.page = 1
  task?.abort()

  try {
    const res = await goodsApi.list(query.value, (t) => (task = t))
    if (reset) list.value = res.list
    else list.value.push(...res.list)
    total.value = res.total
    query.value.page++
  } catch (e) {
    if (!String(e).includes('abort')) uni.showToast({ title: '加载失败', icon: 'none' })
  } finally {
    loading.value = false
  }
}
</script>

请求层透传 RequestTask（给 uni.request 的封装增加 onTask 回调即可，思路见 4.2）。

二、SKU 规格选择器核心算法 ​

规格选择的难点：根据已选规格判断哪些规格值无货可点，以及拼出选中的 SKU。

ts
// src/utils/sku.ts
import type { Sku, SpecValue } from '@/types/goods'

export function findSku(skus: Sku[], selected: number[]): Sku | undefined {
  if (selected.length === 0) return undefined
  const key = [...selected].sort((a, b) => a - b).join(',')
  return skus.find((sku) => [...sku.specValues].sort((a, b) => a - b).join(',') === key)
}

/**
 * 判断某个规格值在当前选择路径下是否可选：
 * 存在至少一个「包含该值且库存>0」的 SKU，且该 SKU 与已选其他规格不冲突。
 */
export function isSpecValueAvailable(
  skus: Sku[],
  selected: Map<number, number>, // groupId -> valueId
  targetGroupId: number,
  targetValueId: number
): boolean {
  return skus.some((sku) => {
    if (sku.stock <= 0) return false
    const values = new Set(sku.specValues)
    if (!values.has(targetValueId)) return false
    for (const [gid, vid] of selected) {
      if (gid === targetGroupId) continue
      if (!values.has(vid)) return false
    }
    return true
  })
}

商详页加入购物车：

async function addToCart() {
  const selectedGroups = specGroups.value.map((g) => selectedMap.value.get(g.id))
  if (selectedGroups.some((v) => !v)) {
    return uni.showToast({ title: '请选择完整规格', icon: 'none' })
  }
  const sku = findSku(spu.value.skus, selectedGroups as number[])
  if (!sku || sku.stock <= 0) {
    return uni.showToast({ title: '该规格已售罄', icon: 'none' })
  }
  cartStore.add({
    skuId: sku.id,
    goodsId: spu.value.id,
    title: spu.value.title,
    spec: specText(selectedMap.value),
    price: sku.price,
    cover: sku.image ?? spu.value.mainImages[0],
    stock: sku.stock
  })
  uni.showToast({ title: '已加入购物车', icon: 'success' })
}

export interface PayParams {
  timeStamp: string
  nonceStr: string
  package: string
  signType: 'RSA' | 'MD5'
  paySign: string
}

export function requestPayment(params: PayParams): Promise<void> {
  return new Promise((resolve, reject) => {
    uni.requestPayment({
      provider: 'wxpay',
      ...params,
      success: () => resolve(),
      fail: (err) => reject(new Error(err.errMsg))
    })
  })

// pages/order/confirm.vue —— 提交流程
import { orderApi } from '@/api/modules/order'
import { requestPayment } from '@/platforms/pay'

const submitting = ref(false)

async function submit() {
  if (submitting.value) return
  if (!items.value.length) return
  submitting.value = true
  try {
    // 1. 服务端锁库存、重算金额、创建订单
    const order = await orderApi.create({
      skuList: items.value.map((i) => ({ skuId: i.skuId, quantity: i.quantity })),
      addressId: address.value?.id,
      couponId: coupon.value?.id,
      remark: remark.value
    })

    // 2. 拉起支付
    try {
      await requestPayment(order.payParams)
    } catch (payErr) {
      // 用户取消/渠道失败：订单已创建，跳订单详情继续支付
      uni.redirectTo({ url: `/pages/order/detail?id=${order.id}` })
      return
    }

    // 3. 支付成功：清理购物车已购项，跳结果页（禁返回到确认页）
    cartStore.removeBySkuIds(items.value.map((i) => i.skuId))
    uni.redirectTo({ url: `/pages/order/result?id=${order.id}` })
  } finally {
    submitting.value = false
  }
}

五、支付结果补单 ​

支付成功回调可能丢失（杀进程、网络切换），结果页与订单详情必须主动查询：

ts
// pages/order/result.vue
onLoad(async (options) => {
  const id = String(options?.id)
  await waitPaid(id, 8000)
})

async function waitPaid(id: string, timeoutMs: number) {
  const start = Date.now()
  while (Date.now() - start < timeoutMs) {
    const order = await orderApi.detail(id)
    if (order.status !== 'pending_payment') return order
    await new Promise((r) => setTimeout(r, 1000))
  }
  // 超时给手动查询入口，不做错误结论
  showManualHint.value = true
}

服务端职责：接收支付渠道异步通知、幂等改订单状态、关单回补库存（9.3 练习）。

六、关键体验细节 ​

  1. 库存售罄按钮置灰但保留可点击提示（告诉用户为什么不能买）。
  2. 价格变化（服务端 reconcile 后）在确认页用醒目动画/提示，不静默改价。
  3. 待支付订单显示服务端返回的剩余支付时间，本地每秒倒计时但不用本地时间决定关单。
  4. 支付中断后从订单列表仍可继续支付或取消。

练习 ​

  1. 实现完整的 SKU 选择弹窗（规格组渲染、无货置灰、选中态、数量步进器），用一组自造多规格数据测试边界。
  2. 把列表页改造成「搜索词改变 300ms 防抖 + 自动取消旧请求」。
  3. 梳理支付失败的三种分支（取消、失败、超时未决）分别应该跳到哪、提示什么。
