4.1 基础入门：uni.request 与异步 API Promise 化 ​

uni.request 全貌 ​

ts
uni.request({
  url: 'https://api.example.com/goods',
  method: 'GET',
  data: { page: 1, size: 20 },
  header: { Authorization: 'Bearer xxx' },
  timeout: 10000,
  success: (res) => {
    console.log(res.statusCode, res.data)
  },
  fail: (err) => {
    console.error(err.errMsg)
  },
  complete: () => {
    uni.hideLoading()
  }
})

关键事实：

  • data 在 GET 下会拼成 query string；POST 下默认按 application/json 序列化。
  • 返回值是 RequestTask，可用来中断请求：task.abort()。
  • 小程序端必须在管理后台配置 request 合法域名（HTTPS）；开发者工具可临时关闭校验。
  • success 只表示网络层成功（HTTP 状态码收到了），401/500 依然进 success——业务错误必须自己判断。

Promise 化：两种方式 ​

方式一：uni.promisify.adaptor（官方推荐，一次性配置） ​

src/main.ts：

ts
import { createSSRApp } from 'vue'
import App from './App.vue'

export function createApp() {
  const app = createSSRApp(App)
  return { app }
}

uni-app Vue3 版中，大多数异步 API 已同时支持 Promise 风格（不传 success/fail 时返回 Promise）。直接写：

ts
async function loadGoods() {
  const [err, res] = await uni.request({
    url: 'https://api.example.com/goods',
    method: 'GET',
    data: { page: 1 }
  }) as [UniApp.RequestError | null, UniApp.RequestSuccessCallbackResult]
  if (err) {
    uni.showToast({ title: '网络异常', icon: 'none' })
    return
  }
  console.log(res.statusCode, res.data)
}

TIP

部分老 API / 第三方插件仍只有回调风格，可用通用适配函数：

ts
export function promisify<T = unknown>(
  fn: (options: any) => void
): (options?: Record<string, unknown>) => Promise<T> {
  return (options = {}) =>
    new Promise((resolve, reject) => {
      fn({
        ...options,
        success: resolve,
        fail: reject
      })
    })
}

方式二：自己包一层（更直观，教学常用） ​

ts
// src/api/request.ts
export interface RequestOptions {
  url: string
  method?: 'GET' | 'POST' | 'PUT' | 'DELETE'
  data?: Record<string, unknown>
  header?: Record<string, string>
  timeout?: number
}

export function http<T = unknown>(options: RequestOptions): Promise<T> {
  return new Promise((resolve, reject) => {
    uni.request({
      method: 'GET',
      ...options,
      success: (res) => {
        if (res.statusCode >= 200 && res.statusCode < 300) {
          resolve(res.data as T)
        } else {
          reject(new Error(`HTTP ${res.statusCode}`))
        }
      },
      fail: (err) => reject(new Error(err.errMsg || '网络异常'))
    })
  })
}

取消请求：RequestTask ​

页面卸载时取消未完成请求，避免回调写入已销毁页面：

ts
import { ref } from 'vue'
import { onUnload } from '@dcloudio/uni-app'

const task = ref<UniApp.RequestTask>()

function search(kw: string) {
  task.value?.abort()
  task.value = uni.request({
    url: 'https://api.example.com/search',
    data: { kw },
    success: (res) => console.log(res.data)
  })
}

onUnload(() => {
  task.value?.abort()
})

配合页面生命周期加载 ​

vue
<script setup lang="ts">
import { ref } from 'vue'
import { onLoad, onPullDownRefresh } from '@dcloudio/uni-app'

interface Goods { id: number; name: string }
const list = ref<Goods[]>([])

onLoad(async () => {
  await fetchList()
})

onPullDownRefresh(async () => {
  await fetchList()
  uni.stopPullDownRefresh()
})

async function fetchList() {
  const res = await uni.request({ url: 'https://api.example.com/goods' })
  list.value = (res as unknown as { data: Goods[] }).data
}
</script>

常见问题 ​

Q：为什么请求在 H5 正常，小程序报“不在以下 request 合法域名列表中”？ 小程序强制域名白名单。开发期在开发者工具勾选「不校验合法域名」，生产期必须在管理后台配置 HTTPS 域名并发布生效。

Q：cookie/session 登录态怎么带？ 小程序不存在浏览器 cookie 机制，登录态要用 token：登录后存 uni.setStorageSync('token', x)，请求时写入 header。跨端 H5 也可统一用 token 方案。

Q：请求默认超时是多少？ 默认 60s（各端可能不同），建议在封装层显式设置 10–15s，给用户明确的失败反馈而不是长时间等待。

Q：能不能直接用 axios？ 小程序端没有 XHR，axios 浏览器适配器不可用（需要第三方小程序适配器，增加维护面）。跨端项目推荐 uni.request 封装；只有纯 H5 子工程才考虑 axios。
