2.1 基础入门：HBuilderX 可视化搭建（Windows/macOS） ​

HBuilderX 是 DCloud 官方 IDE，对 uni-app 的 App 真机运行、云打包支持最好。初学者建议先用它建立正反馈，再切换到 CLI（2.2）。

工具用途WindowsmacOS
HBuilderX 正式版建项目/运行/App 打包✅ 下载正式版安装包✅ 下载 .dmg（区分 Intel/Apple 芯片）

HBuilderX 自带了 uni-app 编译器，仅用 HBuilderX 开发时不需要安装 Node.js。但本教程从 2.2 起全面采用 CLI，建议都装上。

Windows 安装要点 ​

  1. 从 DCloud 官网下载 HBuilderX 正式版（不要用 Alpha 版做生产项目），解压到非系统保护目录，例如 D:\dev\HBuilderX（避免 Program Files 的写权限问题）。
  2. 微信开发者工具安装后：设置 → 安全设置 → 开启服务端口，否则 HBuilderX 无法唤起编译。
  3. Android 真机：设置 → 关于手机 → 连点版本号开启开发者模式 → 打开 USB 调试；安装驱动（多数品牌手机助手会自动装）。
  4. 命令行偏好（可选）：使用 PowerShell 7 / Windows Terminal；若执行 pnpm 提示策略限制，执行：
powershell
Set-ExecutionPolicy -Scope CurrentUser RemoteSigned
  1. 路径中避免中文与空格的老问题在新版已大幅改善，但团队项目仍建议统一使用英文路径。

macOS 安装要点 ​

  1. Apple 芯片（M 系列）与 Intel 芯片下载不同的 dmg，选错版本会出现 Rosetta 相关异常或性能损失。
  2. 首次启动若提示「无法验证开发者」，到 系统设置 → 隐私与安全性 中允许打开。
  3. iOS 真机调试：数据线连接后在手机上点「信任此电脑」；标准基座由 HBuilderX 签名安装，个人免费 Apple ID 也可真机调试，但应用 7 天后需重装。
  4. 微信开发者工具同样需要开启服务端口；macOS 上还要授权「辅助功能/完全磁盘访问」视提示而定。
  5. 推荐通过 Homebrew 安装 Node 生态：brew install node pnpm（或使用 fnm/nvm 管理多版本）。

创建并运行第一个项目 ​

  1. HBuilderX → 文件 → 新建 → 项目 → uni-app → 选 Vue 3 模板，勾选 TypeScript。
  2. 顶部菜单「运行」提供四个目标：
  • 运行到浏览器：直接选 Chrome/Edge，HBuilderX 内置终端会打印本地地址。
  • 运行到小程序模拟器：首次需配置微信开发者工具路径。
  • 运行到手机或模拟器：真机用标准基座；Android 模拟器可用各品牌自带模拟器或第三方。
  • 运行到 App 基座：基座是一个带调试能力的宿主 App，开发阶段代码热更到基座中。

微信开发者工具联调配置 ​

  1. HBuilderX → 工具 → 设置 → 运行配置 → 填写微信开发者工具安装路径。
  2. 微信开发者工具 → 设置 → 安全设置 → 服务端口：开启。
  3. 编译产物默认输出到项目的 dist/dev/mp-weixin，微信开发者工具应导入该目录而不是项目根目录（HBuilderX 会自动唤起；CLI 模式需手动导入一次）。
  4. 在微信开发者工具里：
  • AppData 面板看页面数据（相当于 Vue devtools 的数据视图）
  • Console/Network 看日志与请求
  • Wxml 面板看真实小程序节点

App 真机运行的两种基座 ​

基座用途特点
标准基座日常开发调试HBuilderX 签名，随编译器更新，开箱即用
自定义基座测试原生插件、推送、支付等 SDK需在 manifest 勾选模块后制作，包名/证书与正式包一致

经验法则：功能在标准基座正常但自定义基座异常，优先排查模块勾选与基座版本是否过期（重新制作基座通常能解决一半问题）。

常见问题 ​

Q：HBuilderX 编译卡住或提示插件下载失败？ 网络问题居多。检查代理；企业网络下切换到手机热点验证，确认是网络而非项目问题后再配置镜像。

Q：Windows 上微信开发者工具打不开编译产物？ 先确认服务端口已开启，再检查项目路径是否过深/含特殊字符；CLI 项目确认导入的是 dist/dev/mp-weixin。

Q：macOS 上 M 芯片模拟器/Android 模拟器很慢？ Android Emulator 确认安装的是 arm64 系统镜像；iOS 模拟器只支持部分 uni-app 能力，重能力（推送、蓝牙）请直接真机。

Q：HBuilderX 要不要登录账号？ 云打包、uniCloud 等服务需要 DCloud 账号；本地编译运行不需要。
